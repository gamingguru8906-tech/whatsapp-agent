## Calculation method

- **M-MOBILE-10**: Only the 10-digit mobile number is read. A leading +91, 91 or 0 is removed first. The number must start with 6, 7, 8 or 9.
- **M-ZERO**: Zero is skipped: 8-0-5 is read as 8-5, and 0 never goes on a grid.
- **M-REPEAT**: Repeated digits only matter where a source says so (multiple 6 / multiple 7 on Venus-Ketu). A same-digit pair such as 9-9 has no meaning.
- **M-TWO-GRIDS**: Two separate grids: the birth-date grid (all digits of DD MM YYYY, zeros skipped) and the mobile grid. Yogas are read on each. A planned number changes only the mobile grid.
- **M-X-ABSENT** (needs owner confirmation): On a yoga diagram, a red digit must be present, a red X must be absent, and a blank cell is ignored.
- **M-PROFESSION-CODES** (needs owner confirmation): A 2- or 3-digit profession code matches when those digits are side by side in either order (19 or 91; 371 or 173). 'X AND Y' and single digits match anywhere in the number.
- **M-BIRTH-NUMBER** (needs owner confirmation): Birth number (mulank) = day of birth reduced to one digit. Destiny number (bhagyank) = all digits of the full date of birth added and reduced to one digit. Inferred from T01's example (18 September 2001 → birth 9, destiny 3).
- **M-PERSONAL-YEAR**: Personal year = day + month + digit-sum of the year, reduced fully to one digit (11 → 2, 22 → 4). The calendar year is used: the story shows this year and next year.
- **M-NAME-CHALDEAN** (needs owner confirmation): Name number = sum of the Chaldean values of all letters in the name, reduced to one digit. No source gives the letter table, so the standard Chaldean table below is used; please confirm it.

Chaldean table: 1 = A I J Q Y · 2 = B K R · 3 = C G L S · 4 = D M T · 5 = E H N X · 6 = U V W · 7 = O Z · 8 = F P
